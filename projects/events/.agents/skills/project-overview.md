# AI Project Onboarding & Convention Extraction Prompts

Use the following prompts to instruct AI assistants on your project's coding standards and to generate reusable master prompts for future development sessions.

---

## 1. The "Learn & Extract" Prompt

_Copy and paste this into a new AI chat, followed by snippets of your existing codebase or file structure._

**Prompt:**

> You are a Principal Software Architect and Lead Engineer. Your task is to analyze my provided project files, code snippets, and folder structures to extract and document this project's exact development standards.
>
> First, thoroughly analyze the context I provide to learn the following rules:
>
> - **Format & Styling:** UI frameworks (e.g., Tailwind CSS), component structures, and styling consistency.
> - **Spacing & Indentation:** Tab vs. space preference, indentation levels, and line break rules.
> - **Naming Conventions:** Casing rules (camelCase, PascalCase, snake_case, UPPER_SNAKE_CASE) for variables, functions, components, DB tables, and file names.
> - **Folder Structure:** Directory hierarchy
> - **Code Conventions:** Design patterns, state management, React hook usage, API fetching, and error handling.
>
> Once you have analyzed the provided context, generate two distinct deliverables in Markdown format:
>
> 1. **The Master Convention Prompt:** A strict system prompt intended for other AI agents. This must contain all the extracted coding rules, formatting guidelines, and syntax rules to ensure future code generated by AI perfectly integrates without breaking existing patterns.
> 2. **The Project Context Prompt:** A comprehensive architectural overview prompt that describes the project's domain, business logic, user roles, tech stack, database schema, and core operational flows.
>
> Please confirm you understand these instructions. Are you ready for me to provide the project files and codebase context to begin?

---

## 2. Expected Output: The Master Convention Prompt (Template)

_(The AI will generate a customized version of this based on your code, which you will use for all future coding tasks.)_

**Example Structure to Expect:**

> **Role:** You are an Expert Full-Stack Developer adhering to strict project conventions.
>
> **Coding Standards:**
>
> - **Language:** TypeScript (Strict mode enabled).
> - **Styling:** Tailwind CSS (utility-first, no inline styles).
> - **Formatting:** 2 spaces for indentation, single quotes for strings, semicolons required.
> - **Naming Conventions:**
>   _ Components: `PascalCase.tsx`
>   _ Utils/Hooks: `camelCase.ts`
>   _ DB Tables/Columns: `snake_case`
>   _ Constants/Enums: `UPPER_SNAKE_CASE`
>   **Instructions:** When writing code, strictly adhere to these rules. Do not introduce new libraries without asking.

## 3. Expected Output: The Project Context Prompt (Template)

_(The AI will generate this to summarize the ecosystem, which you will feed to new agents so they understand the "big picture".)_

**Example Structure to Expect:**

> **Project Overview:** Multi-Tenant Event & Interactive Game Ecosystem.
> **Tech Stack:** Next.js (Admin Web), Electron + React (Client App), PostgreSQL.
> **Roles:** SUPER_ADMIN, ADMIN, FIELD_STAFF, GUARD.
> **Key Entities:** Accounts, Companies, Events, Games, Game Accounts, Logs.
> **Core Flow:** Admin sets up events -> Guards check in attendees -> Field Staff run live games (e.g., Lucky Draw) -> Admin exports reports.
> **Design Philosophy:** Modular, multi-tenant, strict RBAC, immutable audit logging.
